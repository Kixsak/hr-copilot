# HR Copilot | FDE Project Summary

**Problem:** Business users need reliable natural-language access to structured HR analytics without bypassing organisational access boundaries.

**My contribution:** Designed and implemented an AI-assisted Python prototype integrating a Claude tool-calling loop with deterministic analytics, role-scoped backend queries, authentication, tests, and local Docker packaging. AI coding assistance was used; design and verification decisions should be discussed transparently.

**Technology:** Python, Streamlit, pandas, Pydantic, Anthropic SDK (Claude API), Docker Compose, pytest.

**Evidence:** Source code, automated tests, reproducible synthetic dataset, and a documented local demo.

**Boundaries:** Local prototype, not a customer production rollout. No public endpoint or independent security certification is claimed.
